# SaudiSensei — منصة تعليمية ثنائية اللغة

هذا المستودع نسخة عرض نظيفة من الشيفرة المصدرية لمنصة **SaudiSensei**، أعددتها لطلب توظيف. المستودع الأصلي خاص، وهذه النسخة مأخوذة من الالتزام المعتمد `570c536` دون سجل Git، ودون أي أسرار أو إعدادات تشغيل أو بيانات.

## نبذة

SaudiSensei نظام لإدارة التعلّم (LMS) يدعم العربية افتراضياً (من اليمين إلى اليسار) والإنجليزية. يضم واجهة للطلاب وأخرى للمشرفين، ونظام اختبارات يُصحَّح آلياً على الخادم بطريقة حتمية.

## الحالة

- **مقبول من مالك المشروع لمرحلة التطوير فقط.** آخر قبول شمل أدوات تأليف الاختبارات للمشرف على متصفح Chrome لسطح المكتب.
- **غير جاهز للإنتاج ولم يُطلق بعد.** ما زالت بوابات ما قبل الإطلاق مفتوحة، ومنها فحوص صلاحيات إضافية وتهيئة الإنتاج والنشر.
- **نسبة الإنجاز التقريبية: نحو 65% — تقدير شخصي مني، وليست قياساً رسمياً.**

## الميزات

العلامة ✅ تعني ميزة مكتملة ومقبولة لمرحلة التطوير. البنود غير المعلّمة مخطط لها ولم تُنفَّذ بعد.

### الأساس والأمان

- ✅ تسجيل الدخول عبر Auth0 من خلال محوّل هوية مستقل عن المزوّد، مع اشتراط البريد الموثّق
- ✅ دورا الطالب والمشرف، مع التحقق من الصلاحيات على الخادم
- ✅ مصادقة متعددة العوامل (MFA) موقّعة لعمليات المشرف
- ✅ سجل تدقيق (Audit) معاملاتي للعمليات الحساسة
- ✅ واجهة متجاوبة بالعربية (RTL) والإنجليزية (LTR)

### إدارة التعلّم

- ✅ إدارة الدورات والفصول والدروس (بصيغة Markdown مقيّدة)
- ✅ تسجيل الطلاب يدوياً، وإلغاء التسجيل، وإعادة تفعيله
- ✅ إكمال الدروس وتتبّع التقدّم
- ✅ صفحات الطالب بتصاميم معتمدة: لوحة الطالب، ودوراتي، ونظرة عامة على الدورة، وعارض الدروس، وبوابة تسجيل الدخول
- ✅ الوسائط في بيئة التطوير: تخزين متوافق مع S3، وفحص الملفات من البرمجيات الخبيثة (ClamAV)، وبث فيديو محمي (Cloudflare Stream)
- بقية ميزات نظام إدارة التعلّم المعتمدة

### الاختبارات والتقييم

- ✅ بنك أسئلة بخمسة أنواع: اختيار واحد، واختيار متعدد، وصح أو خطأ، وترتيب، وتتبّع الشيفرة البرمجية
- ✅ تصنيف المهارات وربط الأسئلة بها
- ✅ بناء الاختبارات ومعاينتها ونشرها، وإصدار المراجعة يدوياً
- ✅ محاولات الطلاب على الخادم، مع الحفظ التلقائي والمواعيد النهائية والتسليم
- ✅ تصحيح آلي حتمي على الخادم، ونتائج ومراجعة لا تكشف مفاتيح الإجابات
- ✅ واجهة المشرف لتأليف الاختبارات (Chrome لسطح المكتب)
- واجهة الطالب لأداء الاختبارات: المؤقّت، والتسليم، وعرض النتائج والمراجعة
- قياس مبسّط للنشاط، وملف مهارات حتمي
- توجيه الطالب إلى المحتوى المناسب بإرشاد حتمي
- تعلّم موجّه بالذكاء الاصطناعي (اختياري)، دون أن يقرر الذكاء الاصطناعي الدرجات أو النتائج
- قبول متكامل وتقوية نهائية لنظام الاختبارات

## التقنيات

- الواجهة: Next.js 16 وReact 19 وTypeScript
- الخادم: NestJS بواجهة REST تحت المسار `/api/v1`
- قاعدة البيانات: PostgreSQL مع Prisma
- الهوية: Auth0
- العقود: OpenAPI، مع عملاء وأنواع مولّدة (Orval وZod)
- مستودع أحادي (Monorepo) بإدارة pnpm
- الاختبارات: `node:test`، في نحو 75 ملف اختبار للخادم والواجهة

## بنية المستودع

- `apps/web` — تطبيق Next.js لواجهتي الطالب والمشرف
- `apps/api` — خادم NestJS واختباراته
- `packages/database` — مخطط Prisma والترحيلات (Migrations) وبذرة الأدوار
- `packages/runtime-config` — فحوص إعدادات التشغيل
- `lib/api-spec` — مواصفات OpenAPI
- `lib/api-zod` و`lib/api-client-react` — شيفرة مولّدة من المواصفات
- `artifacts/mockup-sandbox` — بيئة نماذج التصميم (Mockups)

## التشغيل محلياً (للتطوير فقط)

المتطلبات: Node.js 24، وpnpm 10، وقاعدة PostgreSQL مخصصة للتطوير، ومستأجر Auth0 للتطوير لتسجيل الدخول.

لا يحتوي المستودع على أي ملفات `.env` أو قيم سرية. اضبط المتغيرات في بيئتك المحلية أو في مدير الأسرار، ولا ترفعها إلى Git أبداً.

```bash
pnpm install --frozen-lockfile
pnpm run db:generate
pnpm --filter @workspace/saudisensei-database run migrate:deploy
pnpm run db:seed
pnpm run dev:api
pnpm run dev:web
```

- الأمر `migrate:deploy` يطبّق الترحيلات الموجودة على قاعدة التطوير.
- الأمر `db:seed` ينشئ دورَي الطالب والمشرف فقط، دون أي حسابات.

أسماء المتغيرات المطلوبة (الأسماء فقط):

- الخادم: `DATABASE_URL` و`WEB_ORIGIN` و`APP_BASE_URL` و`AUTH0_DOMAIN` و`AUTH0_AUDIENCE`
- الواجهة: `APP_BASE_URL` و`API_BASE_URL` و`AUTH0_DOMAIN` و`AUTH0_CLIENT_ID` و`AUTH0_CLIENT_SECRET` و`AUTH0_SECRET` و`AUTH0_AUDIENCE`
- اختيارية للوسائط: `S3_*` و`CLOUDFLARE_STREAM_*` و`CLAMAV_DATABASE_DIR` و`VIDEO_PILOT_ENABLED`

الفحوص:

```bash
pnpm run typecheck
pnpm run test
```

اختبارات الخادم تحتاج قاعدة PostgreSQL مخصصة للاختبار. لا تشغّلها على قاعدة إنتاج أبداً.
